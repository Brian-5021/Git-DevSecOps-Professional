# Git-DevSecOps-Professional
Professional labs for Git, GitHub, Application Security and DevSecOps.

## Project Purpose

This repository is a practical learning environment focused on
professional Git workflows, Application Security and DevSecOps.

## Technologies and Practices

- Git and GitHub
- GitHub Actions
- Secure Software Development Lifecycle (SSDLC)
- Static Application Security Testing (SAST)
- Vulnerability Management
- Software Supply Chain Security

## Working Methodology

Changes are developed in separate branches and integrated
through Pull Requests and automated checks.
